# Student-management-system
A Java console-based Student Management System that manages student records efficiently. Users can add, view, update, delete, and search students via a menu-driven interface. The project showcases OOP principles, collections, input validation, and optional file handling.

Student Management System (Java Console-Based)
📌 Description

A console-based Student Management System developed in Java that allows users to manage student records efficiently. The system supports adding, viewing, updating, deleting, and searching student information through a menu-driven interface. It demonstrates core Java concepts such as Object-Oriented Programming (OOP), collections, input validation, and optional file handling, making it suitable for academic and learning purposes.

🎯 Project Objectives

To understand and implement core Java concepts

To apply OOP principles in a real-world scenario

To practice handling user input in console applications

To manage data using Java collections

🛠️ Features

Add new student records

View all students

Search student by ID or name

Update student details

Delete student records

Menu-driven console interface

💻 Technologies Used

Java
